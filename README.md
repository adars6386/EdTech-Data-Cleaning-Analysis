# EdTech Data Cleaning & Analysis Project

## Project Overview
This repository contains the data cleaning workflow and analysis for an EdTech enrollment dataset.

## Files Included
- edtech_dataset_raw.xlsx : The original dataset containing formatting errors, null values, and inconsistent date formats.
- edtech_dataset_cleaned.xlsx : The processed dataset after data cleaning steps.

## Data Cleaning Steps Applied
1. *Null Values Imputation:* Updated missing discount percentages and standardized null discount codes to NONE.
2. *Date Format Standardization:* Converted mixed text date formats into uniform YYYY-MM-DD date objects using Text to Columns.
3. *Duplicate Removal:* Checked and removed duplicate records using Excel's Remove Duplicates tool.
